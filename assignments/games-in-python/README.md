
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. This assignment helps students practice core programming concepts while creating a fun interactive game.

## 📝 Tasks

### 🛠️ Create the Guessing Game

#### Description
Write a Python program that lets a player guess letters to reveal a hidden word before they run out of attempts.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list of words
- Show the hidden word as underscores, such as `_ _ _ _ _`
- Accept one letter at a time from the player
- Reveal correctly guessed letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the player guesses the word or runs out of attempts
- Display a clear win or lose message at the end

### 🛠️ Improve the Game Flow

#### Description
Add simple gameplay polish so the program feels complete and easy to follow during play.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted twice
- Show the letters the player has already guessed
- Keep the game running until the player wins or loses
- Use clear prompts and messages for user interaction
- Include a clean exit condition for the game loop
